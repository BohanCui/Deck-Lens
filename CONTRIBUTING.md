
# Contributing to Deck Lens

Thanks for your interest! Here's how to contribute.

## Before You Start

For small fixes (typos, wording), feel free to open a PR directly.
For bigger changes (new lens, restructuring a mode, etc), please open an issue first so we can discuss.

## Guidelines

- If you update a mode file, please also indicate which language you updated so I can make sure bilingual verions align.
- Keep the tone consistent with the existing files — direct, no jargon, no filler
