
# 模式：Pitch
**适用场景：** 比赛汇报、融资路演、外部客户演示、产品发布

受众是外部人员，他们不了解你。你需要赢得他们的注意，让他们感受到痛点，展示你的方案，最后用一个清晰的行动指令收尾。

---

## 十段 Pitch 叙事结构

| #   | 环节              | 目的                                                                                    |
| --- | --------------- | ------------------------------------------------------------------------------------- |
| 1   | **引入**          | 用趋势、数据或现象开场，让受众自然地产生兴趣。（"近年来，X 越来越……"）                                                |
| 2   | **主题 + 口号**     | 点明汇报主题，喊出一句有力的口号——比如创新、实用、便利。定下整个演示的情绪基调。                                             |
| 3   | **痛点**          | 让受众真切感受到问题的存在。要具体、有共鸣，尽量用真实数字描绘"现在有多痛"。                                               |
| 4   | **现状对比**        | 展示现有方案的不足。根据场景调整：商业场景写友商/竞品，行业场景写普遍做法或行业惯例。如果第1段的背景铺垫还不够，可在此补充行业数据。将自己定位为明确的差距填补者。    |
| 5   | **我们的做法**       | 逐一介绍方案功能，顺序：最基础的 → 最亮眼的。以用户能得到什么为导向，而非技术实现是什么。                                        |
| 6   | **直观展示**        | 真实截图、使用照片或演示录屏。只用真实画面，若为效果图需明确标注。让受众亲眼看见。                                             |
| 7   | **总结对应图**       | 一张幻灯片，将每个痛点与对应解决方案一一映射。让受众一眼看清前后对比的完整闭环。                                              |
| 8   | **定价与授权**       | 这个方案多少钱？包含什么？买方/审批方能获得什么权限或服务？要清晰具体。这张幻灯片建立信任——模糊的报价会扼杀决策。包含：套餐档次（如有）、各档含盖范围、授权或访问条款。 |
| 9   | **上价值**         | 超出今日范围的潜力是什么？预留了哪些扩展空间？传递视野与格局，但不过度承诺。                                                |
| 10  | **回归主题 + 行动指令** | 呼应第2段——同一句口号，同样的气场。然后给出明确的行动指令：你希望受众下一步做什么？（审批、投资、注册、跟进、预约会议。）不能只靠情绪收尾。               |

## 语气要点
- 自信但不夸张
- 痛点要让评委或客户有共鸣，不只是抱怨原厂或竞品
- 功能介绍用"用户能做什么"，而非"我们实现了什么"
- 定价页：直接、诚实。如果是比赛且定价为假设性的，要明确标注
- 行动指令：一个明确的要求，不要多个模糊选项
